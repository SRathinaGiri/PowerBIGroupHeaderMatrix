# Privacy Policy for Group Header Matrix Power BI Custom Visual

Last Updated: July 14, 2026

## 1. Overview

This Privacy Policy describes how the Group Header Matrix Power BI custom visual handles data. The visual is designed to process report data locally inside Microsoft Power BI.

## 2. Data Collection and Transmission

No data collection: The visual does not collect, store, or maintain personal or business data provided through Power BI.

No data transmission: The visual does not transmit data to external servers, APIs, or third-party services. Matrix rendering, formatting, expand/collapse state, sorting, pagination, selection, and tooltip behavior are performed locally within Power BI Desktop or the Power BI Service.

No cookies or tracking: The visual does not use cookies, web beacons, telemetry scripts, or other tracking technologies.

## 3. Report Data

The visual displays only the rows, columns, measures, and optional color values supplied to it by the Power BI report. It does not download data, images, scripts, or other resources from external URLs.

## 4. Third-Party Access

Because the visual does not collect or transmit data, no third parties receive report data through this visual. It operates within the security boundaries defined by the Microsoft Power BI platform.

## 5. Certification Standards

The visual is designed to comply with Microsoft Certified Power BI Visual standards, including no external service or resource access.

## 6. Changes to This Policy

This policy may be updated to reflect changes in the visual, certification requirements, or legal requirements. Updates will be posted in this repository.
